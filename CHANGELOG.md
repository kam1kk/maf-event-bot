# Changelog

## v2.2.0 — 2026-08-18

Запись друга «через /»:

- Новая кнопка «🔗 Друг замена» на сообщении мероприятия: друг
  записывается в одну строку с вами — «kam1kk/mirai». Доступна только
  уже записанным (прикреплять не к чему, если своей записи нет).
- Пара занимает один номер в составе — счётчик игроков не сдвигается;
  в БД это по-прежнему два человека.
- Выписка такого друга — обычные «Выписать друга» и /my; в списках он
  помечен «(через /)». Если выписывается сам хозяин, друг не исчезает,
  а становится отдельной строкой состава.
- Время прихода/ухода у пары общее (хозяйское); чтобы задать другу своё,
  его нужно записать отдельной строкой.

## v2.1.0 — 2026-08-18

Роли (per-группа):

- Админы группы Telegram — автоматически админы бота; права можно
  выдать участнику ответом /promote на его сообщение (снять — /demote
  или из /settings → «Админы бота», только Telegram-админами).
- /settings доступен только админам бота.
- Админы могут управлять любыми столами своей группы.
- Переключатель «создавать мероприятия могут только админы»
  (по умолчанию — все участники).

## v2.0.0 — 2026-08-18

Мультитенантность: один бот обслуживает несколько групп.

- Группы регистрируются автоматически при добавлении бота; у каждой —
  свои типы мероприятий, привязки тем и часовой пояс.
- /new и /settings определяют группу по реальному членству пользователя:
  одна группа — без вопросов, несколько — выбор, ни одной — отказ.
- Планировщик работает по поясу группы-владельца мероприятия.
- Структура БД изменена (отсюда мажорная версия); миграция со старой
  схемы — автоматическая при первом старте.

## v1.5.0 — 2026-08-18

- Настройка часового пояса в /settings: выбор из поясов России или
  ручной ввод IANA-имени. Хранится в БД и приоритетнее TZ из .env
  и системного времени; при смене задачи активных мероприятий
  перепланируются сразу.

## v1.4.0 — 2026-08-17

- Запись друга («+1»): кнопка «➕ Записать друга» — ввод ника в личке
  и то же меню времени (опоздает / уйдёт раньше). Кнопка «➖ Выписать
  друга» появляется на карточке, когда у мероприятия есть гости.
- Друзья рендерятся без ссылки на профиль, управляются через /my тем,
  кто их добавил; дубликат ника при самостоятельной записи допустим.
- Часовой пояс: пустой TZ в .env теперь означает системный часовой
  пояс машины, где запущен бот (tzlocal); явное значение — приоритетнее.

## v1.3.0 — 2026-08-17

- Кнопки «Назад»/«Отмена» на всех шагах текстового ввода: изменение
  даты/времени/места/ведущего в меню управления, форма создания
  мероприятия, ввод времени прихода/ухода. Случайное нажатие больше
  не оставляет бота в ожидании текста.

## v1.2.0 — 2026-08-17

- Ники участников в списках — кликабельные ссылки на профиль Telegram
  (t.me/username, а при его отсутствии — tg://user?id). Без пинг-уведомлений.
- Username сохраняется снапшотом на момент записи; существующая БД
  мигрируется автоматически при старте.
- Создатель мероприятия может выписать любого участника: меню
  «⚙ Управление» → «👥 Выписать участника».
- Отключён предпросмотр ссылок у сообщений мероприятий.

## v1.1.0 — 2026-08-17

- Кнопка «🕐 Со временем» на карточке мероприятия: запись с указанием времени
  прихода/ухода в один поток через личку; для уже записанных — изменение записи.
- Меню времени показывается повторно после ввода — можно сразу указать
  и «приду позже», и «уйду раньше».
- Тесты (pytest): нумерация сверх 10 мест, опоздавшие, пометки времени,
  сдвиг позиций при выписке, отмена стола, парсеры дат.
- CI: починен запуск pytest (pythonpath), workflow зелёный.
- Ники экранируются в HTML-меню; убран устаревший `datetime.utcnow`.
