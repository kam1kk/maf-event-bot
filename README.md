# Mafia Bot

Телеграм-бот для записи на игры в спортивную мафию в группе с темами (forum topics).

## Возможности

- Создание мероприятий по форме (тип, дата, время, место, ведущий) — в личке с ботом, публикация в привязанную тему группы.
- Запись в один клик кнопкой «Записаться»; список редактируется на месте, без новых сообщений.
- Состав нумеруется от 1 до 10 (и дальше при переполнении), опоздавшие — отдельным списком.
- Ник вводится один раз в личке и запоминается; смена ника — /nick (действует только на будущие записи).
- «Приду позже» / «Уйду раньше» — через /my в личке.
- Создатель управляет мероприятием (дата, время, место, ведущий, напоминание, отмена стола) — кнопка «⚙ Управление».
- Запись закрывается автоматически в полночь дня проведения.
- Напоминание за час до начала в выбранную тему (можно отключить для конкретного мероприятия).

## Установка

1. Создайте бота у [@BotFather](https://t.me/BotFather): `/newbot`, скопируйте токен.
2. `cp .env.example .env` и впишите токен в `BOT_TOKEN`.
3. Добавьте бота в группу и назначьте администратором.

### Запуск локально

```bash
pip install -r requirements.txt
python -m bot.main
```

### Запуск в Docker

```bash
docker compose up -d --build
```

## Первичная настройка в группе

1. В теме, где публикуются мероприятия (например, «Сбор столов»), отправьте: `/bind Мафия`
2. В теме для напоминаний отправьте: `/bind_remind Мафия`
3. Готово — любой участник может создать мероприятие через /new в личке с ботом.

Новые типы мероприятий: /settings в личке → «Добавить тип» → затем `/bind <название>` в нужной теме.

## Команды (в личке с ботом)

| Команда | Что делает |
|---|---|
| /new | Создать мероприятие |
| /my | Мои записи: опоздаю / уйду раньше / выписаться |
| /nick | Сменить игровой ник |
| /settings | Типы мероприятий и статус привязки тем |
